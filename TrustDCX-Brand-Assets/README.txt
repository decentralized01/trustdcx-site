TYPOGRAPHY
----------
Wordmark / headlines   Sora 800
Body                   Inter 400–600
Labels / data / mono   JetBrains Mono 500

USAGE
-----
• Clear space ≥ ½ × shield height on all sides.
• Minimum sizes — symbol 32px (UI), 20px (favicon); full lockup 120px wide.
  Below the lockup floor, use the symbol alone.
• Don't recolor the shield gradient, stretch/distort it, add shadows or
  outlines, or place it on clashing colors. Use the reversed white mark on
  busy or colored backgrounds.
